Download Ridga 1.0.2:

Command in terminal:

1: open bash terminal and write 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/TimoNiki/Ridga-cli/refs/heads/main/installer.sh)"

press enter.

2: write your mac password (for install ridga to system files) press enter.

3: wait the end of installing ridga.

4: Done!

Command file:

1: Download the command file. 2: open terminal and write

chmod +x (PATH TO DOWNLOADED FILE)

3: close terminal, and open the downloaded

Ridga Verify is a command, but Ridga executes it in several ways, not just one.
